Google ADK walkthroughs

Twelve step-by-step examples in hos-google-adk/, from a basic greeting agent up to looping multi-agent pipelines. The first six have write-up pages; the rest link straight to the code.

  • hos01 — greeting-agentGitHub— first agent, plus a threat-modeling variant
  • hos02 — multi-agent-with-voiceGitHub— tool agent + voice-enabled variant
  • hos03 — dad-joke-agentGitHub— LiteLLM provider-switching example
  • hos04 — email-agentGitHub— structured outputs with Pydantic schemas
  • hos05 — question-answering-stateful-agentGitHub— sessions and state across turns
  • hos06 — memory-agentGitHub— persistent storage across sessions
  • hos07 — manager-supervisor-agentGitHub— multi-agent orchestration
  • hos08 — customer-service-agentGitHub— stateful multi-agent workflow
  • hos09 — before-after-agent-model-callbacksGitHub— callbacks and event hooks
  • hos10 — lead-qualification-sequential-agentGitHub— sequential pipeline example
  • hos11 — system-monitor-parallel-agentGitHub— parallel orchestration
  • hos12 — linkedin-post-loop-agentGitHub— looping & retry patterns
